* Overview

Unlike some of the editor JSON files, =Everything.ini= mixes real preferences
with a lot of transient UI state. Keep this managed copy focused on the stable
behavior that matters day to day: background indexing, search behavior, history
policy, and the main result-list columns.

* Overview & Architecture

Everything by Voidtools is the backend indexing engine for file searches on Windows.

**Why Everything?**
Windows native search is notoriously slow and unreliable. Everything indexes the MFT (Master File Table) directly, providing instantaneous, sub-millisecond file lookups. We use it as the backend engine for Flow Launcher and command-line es searches, entirely bypassing the Windows indexer.

* Runtime Notes

- This is a curated subset of the full INI, not a byte-for-byte dump of every
  transient window coordinate or UI artifact
- Tangle first, then restart Everything so it reloads the updated INI
- Keep plugin/runtime history files outside this folder; only the main INI is
  treated as the config-of-record
