* Overview

Himalaya — CLI email client used by Hermes Agent to read, search, and manage
email via the built-in =himalaya= skill.

| Key | Value |
|-----+-------|
| Binary | =~/.config/himalaya/bin/himalaya.exe= |
| Config | =~/.config/himalaya/config.toml= |
| Backend | IMAP (read) + SMTP (send) |

* Configuration

The following block tangles to =~/.config/himalaya/config.toml=.

Config is gitignored (=.gitignore= excludes =config.toml=). Password stored in
Windows Credential Manager, retrieved at runtime by =get-pass.ps1= (see
[[file:~/.config/scripts/scripts.org][scripts.org]]).

* Overview & Architecture

Himalaya is a CLI email client.

**Why Himalaya?**
By moving email out of heavy web clients and into a CLI tool, email processing becomes instantly accessible via standard terminal multiplexing. It fits perfectly into the keyboard-driven, ADHD-optimized philosophy by removing visual distractions inherent to web-based email.

* Credential Management

Password stored in Windows Credential Manager via =PasswordVault=, not on
disk. Two helper scripts in =~/.config/scripts/himalaya/=:

- =get-pass.ps1= — Retrieved by himalaya's =backend.auth.cmd= at connect time.
- =set-pass.ps1= — One-shot setup: =set-pass.ps1 "your-app-password"=

Source: [[file:~/.config/scripts/scripts.org][scripts.org]] (look for =* Himalaya=).

* Quick Reference

| Command | Effect |
|---------+--------|
| =himalaya envelope list -f INBOX -s 10= | Last 10 inbox messages |
| =himalaya envelope search "query"= | Search email |
| =himalaya message read <id>= | Read a message |
| =himalaya message send= | Compose and send |

* Integration with Hermes

Hermes uses the =himalaya= skill (built-in) to check email. Send
"check my email" on Telegram and Hermes will use himalaya to fetch,
summarize, and advise.
