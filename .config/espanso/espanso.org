* Overview

Espanso is the system-wide text expander for short reusable snippets that should
work outside editor-specific snippet systems: dates, timestamps, Org bullets,
and lightweight note-link scaffolds.

* Default Configuration

Start with conservative global defaults; add app-specific configs later if needed.

* Overview & Architecture

Espanso is the system-wide text expansion engine.

**Why Espanso?**
While editors like Emacs and VS Code have their own powerful snippet systems (YASnippet, etc.), those snippets are locked inside the editor. Espanso runs at the OS level, meaning the exact same text expansions work perfectly in the browser, the shell, Discord, and anywhere else. It guarantees absolute consistency in text input across the entire Windows environment.

* Base Matches

The starter match file focuses on broadly useful text expansion without trying
to replace the richer structure already handled by Org, Howm, or Denote.

#+begin_src yaml :tangle match/base.yml :mkdirp yes
# yaml-language-server: $schema=https://raw.githubusercontent.com/espanso/espanso/dev/schemas/match.schema.json

# =============================================================================
# DO NOT EDIT THIS FILE DIRECTLY.
# Generated from ~/.config/espanso/espanso.org
# Edit that file, then restart Espanso after tangling.
# =============================================================================

matches:
  - trigger: ":espanso"
    replace: "Hi there!"

  - trigger: ":date"
    replace: "{{today}}"
    label: Insert date as YYYY-MM-DD
    vars:
      - name: today
        type: date
        params:
          format: "%Y-%m-%d"

  - trigger: ":time"
    replace: "{{now}}"
    label: Insert time as HH:MM
    vars:
      - name: now
        type: date
        params:
          format: "%H:%M"

  - trigger: ":now"
    replace: "{{stamp}}"
    label: Insert timestamp as YYYY-MM-DD HH:MM
    vars:
      - name: stamp
        type: date
        params:
          format: "%Y-%m-%d %H:%M"

  - trigger: ":orgts"
    replace: "{{orgstamp}}"
    label: Insert Org timestamp like [2026-05-14 Thu 09:30]
    vars:
      - name: orgstamp
        type: date
        params:
          format: "[%Y-%m-%d %a %H:%M]"

  - trigger: ":log"
    replace: "- {{orgstamp}} "
    label: Insert Org-style log bullet with timestamp
    vars:
      - name: orgstamp
        type: date
        params:
          format: "[%Y-%m-%d %a %H:%M]"

  - trigger: ":todo"
    replace: "- [ ] "
    label: Insert unchecked task bullet

  - trigger: ":orgtodo"
    replace: "TODO "
    label: Insert Org TODO keyword

  - trigger: ":denote"
    replace: "[[denote:$|$]]"
    label: Insert denote link skeleton

  - trigger: ":orglink"
    replace: "[[$|$]]"
    label: Insert Org link skeleton
#+end_src

* Runtime Notes

- =match/packages/= is managed by Espanso packages and is not the hand-edited
  source of truth
- Restart path: =espansod.exe restart=
- Startup registration currently remains user-scoped through =espanso.lnk=
  because moving that shortcut to the common Startup folder hit an access
  denied error
