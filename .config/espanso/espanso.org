⚠ *DO NOT EDIT =config/default.yml= OR ANY FILE IN =match/= DIRECTLY.*

This =espanso.org= file is the source of truth for the active Espanso setup.
Edit here, then tangle with =tangle espanso= (or
=M-x org-babel-tangle=), then restart Espanso.

On Windows, Espanso expects its runtime config at =%APPDATA%\espanso=. That
path is now a junction back to =~/.config/espanso= so the live runtime files
and the literate source stay in one place.

Espanso automatically loads all =.yml= files in the =match/= directory, so
splitting triggers across multiple files is seamless.
#+end_quote

* Overview

Espanso is the system-wide text expander for short reusable snippets that should
work outside editor-specific snippet systems: dates, timestamps, Org bullets,
and lightweight note-link scaffolds.

**Why Espanso?**
While editors like Emacs and VS Code have their own powerful snippet systems
(YASnippet, etc.), those snippets are locked inside the editor. Espanso runs at
the OS level, meaning the exact same text expansions work perfectly in the
browser, the shell, Discord, and anywhere else.

**Architecture**

Espanso config is split across multiple match files for maintainability:

| File | Purpose |
|------|---------|
| =match/base.yml= | Core: timestamps, Denote helpers, journal logging, task helpers |
| =match/links.yml= | URLs: website, GitHub profile |
| =match/personal.yml= | Contact info + local paths: email, phone, address, signature, home, notes, config, projects (gitignored) |
| =match/code-fences.yml= | Org source/quote/example block templates per language (generated by emacs-lisp) |
| =match/date-math.yml= | Relative date shortcuts: tomorrow, yesterday, next week, etc. |

* Code Fences (Org Blocks)

Org source code blocks, quote blocks, and example blocks for common languages.
Generated via Emacs Lisp to avoid `#+begin_src`/`#+end_src` parsing issues with
org-babel-tangle.

NOTE: Code fence YAML cannot live in a tangled =#+begin_src yaml= block because
=#+begin_src= and =#+end_src= inside replacement text break org-babel parsing.
Instead, a PowerShell block below generates the file on demand.

Run =M-x org-babel-execute-src-block= on the block below (or =C-c C-c= with
cursor inside it) to regenerate =match/code-fences.yml=.

#+name: gen-code-fences
#+begin_src powershell :results silent :exports both
$file = Join-Path (Get-Location) "match/code-fences.yml"
$langs = @(
  @{Name="rust"; Suffix="rs"},
  @{Name="typescript"; Suffix="ts"},
  @{Name="python"; Suffix="py"},
  @{Name="powershell"; Suffix="ps"},
  @{Name="yaml"; Suffix="yaml"},
  @{Name="csharp"; Suffix="cs"},
  @{Name="javascript"; Suffix="js"},
  @{Name="json"; Suffix="json"},
  @{Name="bash"; Suffix="bash"},
  @{Name="org"; Suffix="org"},
  @{Name="emacs-lisp"; Suffix="elisp"},
  @{Name="css"; Suffix="css"},
  @{Name="html"; Suffix="html"},
  @{Name="dockerfile"; Suffix="dockerfile"},
  @{Name="toml"; Suffix="toml"},
  @{Name="sql"; Suffix="sql"}
)
# Use double-quoted YAML strings with \n for reliable newlines
$lines = [System.Collections.ArrayList]@(
  "# yaml-language-server: `$schema=https://raw.githubusercontent.com/espanso/espanso/dev/schemas/match.schema.json",
  "# =============================================================================",
  "# DO NOT EDIT THIS FILE DIRECTLY.",
  "# Generated from ~/.config/espanso/espanso.org",
  "# Edit that file, then restart Espanso after tangling.",
  "# =============================================================================",
  "",
  "matches:"
)
foreach ($lang in $langs) {
  $trigger = ":s-$($lang.Suffix)"
  $replace = "#+begin_src $($lang.Name)\n\n#+end_src"
  [void]$lines.Add("")
  [void]$lines.Add("  - trigger: `"$trigger`"")
  [void]$lines.Add("    replace: `"$replace`"")
  [void]$lines.Add("    label: Insert $($lang.Name) code block")
}
[void]$lines.Add("")
[void]$lines.Add("  - trigger: `":quote`"")
[void]$lines.Add("    replace: `"#+begin_quote\n\n#+end_quote`"")
[void]$lines.Add("    label: Insert Org quote block")
[void]$lines.Add("")
[void]$lines.Add("  - trigger: `":example`"")
[void]$lines.Add("    replace: `"#+begin_example\n\n#+end_example`"")
[void]$lines.Add("    label: Insert Org example block")
$content = $lines -join "`r`n"
Set-Content -Path $file -Value $content -Encoding UTF8
Write-Output "Generated $file"
#+end_src

* Date Math

Relative date shortcuts for journaling and planning. Uses the built-in Date
extension with offset parameter (no shell needed).

#+begin_src yaml :tangle match/date-math.yml :mkdirp yes
# yaml-language-server: $schema=https://raw.githubusercontent.com/espanso/espanso/dev/schemas/match.schema.json

# =============================================================================
# DO NOT EDIT THIS FILE DIRECTLY.
# Generated from ~/.config/espanso/espanso.org
# Edit that file, then restart Espanso after tangling.
# =============================================================================

matches:
  - trigger: ":tomorrow"
    replace: "{{mytime}}"
    label: Insert tomorrow's date (YYYY-MM-DD)
    vars:
      - name: mytime
        type: date
        params:
          format: "%Y-%m-%d"
          offset: 86400

  - trigger: ":yesterday"
    replace: "{{mytime}}"
    label: Insert yesterday's date (YYYY-MM-DD)
    vars:
      - name: mytime
        type: date
        params:
          format: "%Y-%m-%d"
          offset: -86400

  - trigger: ":nextweek"
    replace: "{{mytime}}"
    label: Insert date 7 days from now (YYYY-MM-DD)
    vars:
      - name: mytime
        type: date
        params:
          format: "%Y-%m-%d"
          offset: 604800
#+end_src

* Runtime Notes

- =match/packages/= is managed by Espanso packages and is not the hand-edited
  source of truth
- Restart path: =espansod.exe restart=
- Startup registration currently remains user-scoped through =espanso.lnk=
  because moving that shortcut to the common Startup folder hit an access
  denied error
