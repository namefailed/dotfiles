=Microsoft.PowerShell_profile.ps1=. It aims for a fast interactive shell with
Vi-style editing, Catppuccin coloring, lazy-loaded extras, and a handful of
workflow helpers.

* Performance

Startup is optimized through several strategies:

- *Batched command checks*: All external commands are checked once at startup
  via a single PATH enumeration, cached in =$__cmds= for reuse
- *Deferred Az.Tools.Predictor*: Loads asynchronously after first prompt appears,
  avoiding the slow =Get-Module -ListAvailable= call on every startup
- *Lazy directory creation*: =~/.marks= is created only when you first use =mark=
- *Stream-based history*: =Ctrl+r= uses =[System.IO.File]::ReadLines()= for
  efficient handling of large history files

* Reload

The =tangle= command behaves like this:

- =tangle all= -- run the batch tangle across =~/.config= (via =utility/tangle-configs.ps1=)
- =tangle <document>= -- tangle one Org source by full path, path under
  =~/.config=, or a unique bare stem such as =kanata=
