* What Pan is

A *second* Hermes Agent (v0.15.1), running in *WSL2 Ubuntu* on the GPU laptop
(referred to here as =pan-gpu=, my account =grey=). The main PC runs Hermes *natively on Windows*;
Pan runs in WSL — intentionally different. Pan = the GPU-bearing child of Hermes.

* Relationship to this repo

- This main-PC dotfiles repo is unchanged by Pan; Pan keeps its own =~/.config/hermes=.
- The two nodes share the same provider keys (=opencode-go=/=opencode-zen=) and the
  same Basic Memory brain (Pan tunnels to main's MCP).
- Both should run the *same* Ollama model (=OLLAMA_MAX_LOADED_MODELS=1= → otherwise thrash).
