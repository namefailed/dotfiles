* Overview & Architecture

Hermes is a command-line utility for managing local and remote datasets or configurations.

**Design Philosophy**
It is kept minimally configured, acting as a lightweight shim for data transfer workflows within the ecosystem.

Bootstraps: uv, Python 3.11, Node 22, ffmpeg, Playwright.

After install, =HERMES_HOME= was set and data migrated from
=%LOCALAPPDATA%\hermes=.

* Providers

| Provider | Model | Auth | Status |
|----------+-------+------+--------|
| OpenCode Go | deepseek-v4-flash, kimi-k2.6, glm-5.1 | API key (subscription) | Primary ($10/mo flat) |
| OpenCode Zen | deepseek-v4-flash, gpt-5.4-nano | API key (paid) | Fallback 2 (credit burn) |
| GitHub Copilot | gpt-4o | =gh auth token= | Fallback 3 (free, limited msgs) |
| Google Gemini | gemini-3-flash-preview | Cloud Code PA OAuth | Manual only (free, RPS-limited) |
| Ollama (local) | llama3.2:3b / qwen2.5-coder:1.5b | None (localhost) | Auxiliary (compression) |
| OpenAI Codex | gpt-5.3-codex | OAuth device code | Manual only (rate limited) |

** Gemini (Manual Only)

Configured via =hermes model= (option 16). Uses Google OAuth via the Cloud
Code PA mechanism — credentials stored outside =auth.json=. Also has a
standalone API key in =.env= (=GEMINI_API_KEY=) for backup/auxiliary use.
Excluded from auto-fallback due to per-minute RPS limits.

** OpenAI Codex (Manual Only)

Configured via =hermes auth add --type oauth --no-browser openai-codex=.
Rate-limited on the free plan (resets ~2 PM CT daily). Not in auto-fallback
chain.

** GitHub Copilot (Fallback 3 / Last Resort)

Auto-detected from =gh auth token=. Use with =--provider copilot --model gpt-4o=.

** OpenCode Go (Primary)

Default provider — $10/month subscription providing open models via API.
Key stored in =.env= (=OPENCODE_GO_API_KEY=). Base URL auto-detected from
=OPENCODE_GO_BASE_URL= (=https://opencode.ai/zen/go/v1=).

Available models: deepseek-v4-flash (default/primary), kimi-k2.6 (fallback 1), glm-5.1, minimax-m2.7.

Added to Hermes via:
#+begin_src powershell
hermes auth add --type api-key "opencode-go" --api-key "<key>" --label "opencode-go-subscription"
#+end_src

** OpenCode Zen (Fallback 2)

Paid-tier fallback with access to gpt-5.4-nano and many other models.
Key stored in =.env= (=OPENCODE_ZEN_API_KEY=). Base URL auto-detected from
=OPENCODE_ZEN_BASE_URL= (=https://opencode.ai/zen/v1=).

Added to Hermes via:
#+begin_src powershell
hermes auth add --type api-key "opencode-zen" --api-key "<key>" --label "opencode-zen-credit"
#+end_src

** Ollama (Local / Auxiliary)

Local models for cheap auxiliary tasks (context compression). No API key
needed — runs on localhost:11434 via the built-in =custom= provider.

Models installed:
- =qwen2.5-coder:1.5b= (986 MB, ~30-50 tok/s) — default compression model
- =llama3.2:3b= (2.0 GB, ~8-15 tok/s) — backup

Configured under =auxiliary.compression= in config.yaml below.

** Cron Jobs

Three scheduled jobs run daily, delivering results to Telegram:

| Job | Schedule | Description |
|-----|----------|-------------|
| =daily-tangle-check= | 9 AM | Run tangle-check, report config drift |
| =daily-pkm-digest= | 7 PM | New notes, orphan links, journal reminder |
| =daily-git-reminder= | 8 PM | Uncommitted/unpushed work across repos |

Managed via =hermes cron list=, =hermes cron edit=, =hermes cron remove=.

** Basic Memory MCP

Hermes connects to Basic Memory's MCP server at =http://127.0.0.1:8765/mcp=
using the built-in native MCP client. This gives Hermes the ability to:
- =write_note=: Create or update notes in Basic Memory
- =read_note=: Read note contents
- =search_notes=: Semantic search across the knowledge base
- =build_context=: Assemble relevant context for a query

Configured under =mcp_servers.basic-memory= in config.yaml (see above).

* Quick Reference

  | Command | Effect |
  |---------+--------|
  | =hermes chat= | Default: gemma4:e4b (pan-gpu, primary) |
  | =hermes chat --provider opencode-go --model deepseek-v4-flash= | Fallback 1 (opencode-go, deepseek-v4-flash) |
  | =hermes chat --provider opencode-zen --model deepseek-v4-flash= | Fallback 2 (opencode-zen, deepseek-v4-flash) |
  | =hermes chat --provider google-gemini-cli= | Gemini (free, RPS-limited) |
  | =hermes chat --provider custom --model llama3.2:3b= | Local: Ollama (CPU only) |
  | =hermes cron list= | List scheduled jobs |
  | =hermes cron add ...= | Schedule a new job |
