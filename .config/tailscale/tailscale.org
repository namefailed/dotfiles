* Overview

This directory holds the TLS certificate and private key issued by Tailscale for this
node's MagicDNS hostname. These files are *not* generated by tangling — they are
produced by running:

#+begin_example
tailscale cert grey.tail9339e.ts.net
#+end_example

That command must be run from a privileged context (admin shell or with the Tailscale
daemon running). The files are stored here rather than in the home root so that the
certificate directory has a well-defined, auditable location.

* Files

| File | Purpose |
|------+---------|
| =grey.tail9339e.ts.net.crt= | X.509 TLS certificate for the Tailscale node |
| =grey.tail9339e.ts.net.key= | Corresponding private key (600 permissions on Unix) |

* Usage

These certs are available for any local service that needs HTTPS over the Tailscale
network (e.g. a locally-hosted dashboard, API endpoint, or self-hosted tool).

The =ttyd= web terminal runs over plain HTTP on the Tailscale interface and does *not*
currently consume these certs directly — the Tailscale layer provides the transport
security.

* Certificate Renewal

Tailscale certificates are short-lived (typically 90 days). When renewal is needed,
re-run the =tailscale cert= command above in this directory:

#+begin_src powershell :tangle no
cd ~\.config\tailscale
tailscale cert grey.tail9339e.ts.net
#+end_src

* Overview & Architecture

Tailscale is a zero-config VPN based on WireGuard.

**Design Philosophy**
Tailscale provides the secure, zero-trust network backbone for all remote access into this development environment. It completely eliminates the need for port forwarding or complex firewall rules, seamlessly bridging the Windows machine to external devices.

* Notes

- The private key should never be committed to yadm. Ensure =.gitignore= or
  =~/.config/yadm/= excludes =*.key= under this path.
- The =.crt= file is public and safe to version-control if desired.
