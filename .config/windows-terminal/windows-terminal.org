* Overview

Windows Terminal is the main interactive shell surface for the desktop stack.
This config keeps PowerShell 7 front-and-center, aligns the theme with the rest
of the environment, and adds Vim-friendly tab and pane navigation.

* Core Settings

** Initial Configuration

Start with PowerShell 7 as default. Acrylic enabled on tab row.
Unfocused acrylic compatibility mode keeps transparency working when
the window loses focus.

* Keybindings

Custom shortcuts for efficient terminal navigation.
- =ctrl+h/l= and =ctrl+,/.= — previous/next tab
- =ctrl+alt+h/j/k/l= — move focus between panes (Vim-style)
- =ctrl+\/−= — split pane right/down
- =ctrl+r= — rename the current tab
- =ctrl+1= through =ctrl+9= — switch to tab 0–8; =ctrl+0= switches to tab 9
- =shift+enter= — send Escape+Enter (cancel + submit blank line)
