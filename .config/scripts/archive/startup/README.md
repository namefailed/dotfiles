Archived startup shortcuts
==========================

These are the shortcuts that previously lived in
`%ProgramData%\...\StartUp\`. They were replaced by
`startup-orchestrator.vbs` on 2026-05-18.

To restore the old startup behavior, copy all `.lnk` files
back to the ProgramData Startup folder (requires elevation).

`basic-memory.vbs` was a standalone VBS file — its archived
copy is at `../vbs/basic-memory.vbs`.
