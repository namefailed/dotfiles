#+title:      Scripts
#+date:       [2026-05-13 Tue]
#+filetags:   :config:

Automation scripts for the Windows desktop stack. Flat layout under
=~/.config/scripts/= (no =scripts/powershell/= prefix).

* Files

- =scripts.org= — Literate source for all scripts; tangle with =tangle scripts=
- =_lib/config-paths.ps1= — Shared path helpers (=ConfigScriptsRoot= → =scripts/=)
- =kanata/=, =komorebi/=, =remote/=, =basic-memory/=, =phoneme/=, =startup/=, =utility/=, =wtq/= — Active scripts
- =archive/= — Superseded scripts (AHK/WHKD era, retired drift check, org-protocol installer)

* Directory layout

#+begin_example
~/.config/scripts/
  _lib/           config-paths.ps1
  kanata/         Kanata-invoked launchers
  komorebi/       Window manager helpers + VBS wrappers
  remote/         SSH, ttyd, Tailscale
  basic-memory/   MCP server, cron, export
  phoneme/        dev-phoneme stack launcher
  startup/        startup-orchestrator.vbs → deploy-startup (admin)
  utility/        tangle, drift check, PKM verify, org-capture
  wtq/            Howm dropdown launcher
  archive/        Retired scripts
#+end_example

* Configuration

Edit =scripts.org=, then =tangle scripts= (or =M-x org-babel-tangle= on =scripts.org=).
Never edit generated =.ps1= / =.vbs= directly unless unblocking an emergency (re-tangle after).

* Portability

- =ConfigScriptsRoot= in [[file:_lib/config-paths.ps1][config-paths.ps1]] is =~/.config/scripts=
- Profile forces the same path after dot-sourcing =config-paths.ps1=
- After tangling =startup-orchestrator.vbs=, redeploy: =deploy-startup= (admin)
