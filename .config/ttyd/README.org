* Overview

ttyd shares a terminal over HTTP + WebSocket, enabling remote shell access from
a phone or tablet browser without installing an SSH client. It is not tangled
from this directory — =ttyd.org= is a literate reference only.

* Files

- =ttyd.org= — Reference documentation (no tangled output)

* Configuration

| Setting       | Value                          |
|---------------+--------------------------------|
| Version       | 1.7.7                          |
| Installed via | winget (=tsl0922.ttyd=)       |
| Port          | 7681                           |
| Shell         | =cmd.exe= (pwsh crashes ttyd)  |
| Trigger       | On-demand via =webterm= alias  |

* Security

- Bound to =0.0.0.0:7681= but only reachable through the Tailscale interface
- No authentication layer — Tailscale mesh VPN is the sole access control
- Start only when needed, stop when done
- A custom firewall rule (=Profile Any=) was created because the Tailscale
  adapter uses the Private profile; see =enable-ttyd-firewall.ps1=
