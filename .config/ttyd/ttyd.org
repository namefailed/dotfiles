* Overview

=ttyd= shares a terminal over HTTP + WebSocket. A phone browser can open
a full PowerShell prompt without installing an SSH client.

| Setting      | Value                           |
|--------------+---------------------------------|
| Version      | 1.7.7                           |
| Installed via| winget (tsl0922.ttyd)           |
| Real binary  | =WinGet\Packages\...\ttyd.exe=  |
| Port         | 7681                            |
| Shell        | =cmd.exe= (=pwsh.exe= crashes ttyd — root cause unknown) |
| Trigger      | On-demand (=toggle-ttyd.ps1=)   |

* Security

ttyd is bound to =0.0.0.0:7681= but only reachable through the Tailscale
interface (=100.x.x.x=). It has no authentication layer — the Tailscale
mesh VPN is the sole access control. Start only when needed, stop when done.

A custom firewall rule was created with =Profile Any= because the default
winget rule scopes to the Public profile, but the Tailscale virtual adapter
uses the Private profile. See =enable-ttyd-firewall.ps1= for the rule.
