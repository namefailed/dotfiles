* Overview & Architecture

gh is the official GitHub CLI tool.

**Design Philosophy**

We use gh extensively for managing PRs, issues, and authentication without leaving the terminal. It acts as the primary credential helper for Git, ensuring secure, token-based authentication seamlessly integrates with the Windows credential manager.
