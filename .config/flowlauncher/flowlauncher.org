* Overview & Architecture

Flow Launcher is the keyboard-first application and workflow launcher.

*** Why Flow Launcher?
The native Windows Start Menu is bloated with web searches and advertisements. Flow Launcher provides a clean, instantaneous, keyboard-driven interface. Backed by the Everything search engine, it guarantees immediate access to any file, app, or system command without taking your hands off the keyboard.

* Overview

Flow Launcher is the keyboard-first launcher surface for the Windows desktop.
This file defines the core window behavior, custom explorers and browsers, and
the plugin keywords that make the launcher feel like part of the rest of the
tooling stack rather than a separate app.
