* Delta Diff Viewer

[[https://github.com/dandavison/delta][delta]] provides syntax-highlighted, line-numbered, side-by-side diffs
as the default git pager. Already installed via winget.

#+begin_src conf :tangle config
[core]
    pager = delta

[delta]
    navigate     = true
    line-numbers = true
    side-by-side = true

[interactive]
    diffFilter = delta --color-only
#+end_src

* Overview & Architecture

Git is the global version control system.

**Why this config?**
This literate config acts as the global ~/.gitconfig. It forces consistent identity, enables the Windows credential manager (via Git for Windows or GitHub CLI), and ensures pull behaviors (like rebase) are deterministic and safe across all repositories on this machine.

* Runtime Notes

- Reload path: Git reads =~/.config/git/config= on demand (XDG-native), so
  there is no separate service restart step.
- The old =~/.gitconfig= home-root file has been removed. Git does *not* fall
  back to it when the XDG path is present.
- Keep secrets out of this file; use Git Credential Manager, the GitHub CLI,
  or host-specific credential helpers instead of hand-written tokens.
