* Purpose

[[https://yadm.io/][yadm]] versions dotfiles with normal Git, while keeping the work tree at =~/= so paths
stay where Windows and your tools expect them. This folder (=~/.config/yadm/=) only
holds *yadm-specific* helpers; the repo-wide policy lives in =~/.gitignore= at the
home root.

See also the top-level map: [[file:../README.org][~/.config/README.org]].

* How this fits literate config

- *Edit surface*: keep changing =*.org= under =~/.config/= and tangling (see
  [[file:../README.org::*Tangling][~/.config/README.org → Tangling]]).
- *History / sync*: use =yadm add= / =yadm commit= / =yadm push= for anything the
  root =~/.gitignore= whitelists (today: mostly =~/.config/**= plus =~/.gitconfig=).
  The Doom *core* checkout at =~/.config/emacs/= is **not** in yadm (nested upstream
  Git repo); clone it in =bootstrap= or reinstall Doom the usual way — your layer stays in =~/.config/doom/=.
- *New machine*: =yadm clone <url>= then =yadm bootstrap= (runs =~/.config/yadm/bootstrap=).

* Installed layout (this machine)

| Path | Role |
|------+------|
| =~/bin/yadm= | Upstream yadm bash script (currently 3.5.0) |

| =~/.ssh/config= | =Host github.com= uses =~/.ssh/id_ed25519_github= (no passphrase) so Git works without =ssh-agent= |
| =~/.ssh/id_ed25519_github= | Passphrase-less key registered on GitHub for this PC |
| =~/.ssh/id_ed25519= | Older bcrypt-encrypted key (same pubkey as key =grey_lenovo= on GitHub) — use only with =ssh-agent= + =ssh-add= if you need it |

After changing =PATH=, open a *new* terminal so =yadm= resolves to =~/bin/yadm.cmd=.

* Operator checklist

1. =yadm version= — sanity check after shell restart.
2. Review / extend =~/.gitignore= (whitelist =!= lines for extra top-level dotfiles).
3. =yadm status= — expect many untracked paths until ignores match your intent; prefer =yadm add -p= over blind =yadm add -A=.
4. =yadm remote add origin <url>= when you have a private host (GitHub, etc.).
5. =yadm commit= and =yadm push= when satisfied (hooks and signing follow your global Git config).

* Clone on a fresh system

#+begin_example
yadm clone https://github.com/<you>/dotfiles.git
yadm bootstrap    # runs ~/.config/yadm/bootstrap
#+end_example

* Bootstrap

=yadm bootstrap= executes =~/.config/yadm/bootstrap= (bash). Edit that script for
non-interactive installs (=winget=, =uv=, Emacs build deps, etc.) on new hardware.
