#+begin_quote
⚠ *DO NOT EDIT =settings.json= OR =keybindings.json= DIRECTLY.*

This =windsurf.org= file is the source of truth for the active Windsurf
profile. Edit here, then tangle with
=tangle windsurf= (or =M-x org-babel-tangle=)
and reload Windsurf for changes to take effect.

On Windows, Windsurf reads its user config from =%APPDATA%\Windsurf\User=. The
managed runtime files should resolve back to =~/.config/windsurf= so the live
editor profile and the literate source stay together.
#+end_quote

* Overview

The current Windsurf profile is intentionally minimal: disable editor preview
tabs and keep the Devin ACP agents enabled. Leave keybindings empty until there
is a real override worth preserving.

* Overview & Architecture

Windsurf is a lightweight, AI-first editor profile.

**Design Philosophy**
As an experimental AI workspace, this configuration is kept exceptionally lean. It inherits from the core VS Code aesthetic but minimizes local overrides, ensuring the AI agent has a clean, predictable workspace without battling complex custom keybindings.
