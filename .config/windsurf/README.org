* Overview

=windsurf.org= is the source of truth for the active Windsurf profile. It
tangles to =settings.json= and =keybindings.json=, which the runtime reads via
the managed files under =%APPDATA%\Windsurf\User=.

* Files

- =windsurf.org= -- source of truth
- =settings.json= -- tangled Windsurf settings
- =keybindings.json= -- tangled Windsurf keybindings

* Current Policy

- Keep the profile intentionally small until Windsurf earns more permanent
  editor-specific customization
- Preserve the current ACP agent enablement
- Keep keybindings empty until there is a real override worth saving

* Reload

After editing =windsurf.org=, =tangle windsurf= and reload Windsurf.
