* Overview

Tridactyl is a Vim-modal keyboard extension for Firefox. It replaces the mouse
for almost all browsing tasks: link following, scrolling, tab management,
clipboard operations, and URL manipulation.

The config is deliberately comprehensive — the goal is keyboard-first
browsing with no reaching for the mouse. Key philosophy:

- =h/l= scroll left/right; =d/u= scroll page up/down (Vim half-page convention)
- =H/L= navigate tab history; =J/K= go back/forward in page history
- =f/F= hint in same/new tab; =;Y/;m= image copy/Google Lens
- =bind gs*= prefixes for domain-scoped searches
- =yo= / =yl= / =yt= — Org link to clipboard / journal Log / journal Tasks (org-protocol)
- Aliases provide complex single-key actions (translate, URL tools, mpv)

Reference: [[https://tridactyl.xyz/][Tridactyl website]] | [[https://github.com/tridactyl/tridactyl][Tridactyl GitHub]]

* General Settings

Core behaviour tweaks applied globally.

- =set hintchars asdfghjkl= — home-row characters for hint labels; faster to type
  than alphabetical labels since fingers rest on the home row.
- =update.nag= / =update.nagwait= / =update.checkintervalsecs= keep update
  notifications enabled without tracking volatile "last checked" timestamps in
  the source file.
- =hintfiltermode vimperator-reflow= — type characters to filter hints by link
  text, reflow positions as you narrow the set.
- =hintdelay 50= — small delay before hints appear; prevents flicker on fast pages.
- =hintuppercase true= — uppercase hint labels are easier to scan visually.
- =hintautoselect true= — auto-follow a hint when it's the only one remaining.
- =hintshift true= — hold Shift to open hint in a background tab.
- =modeindicatorshowkeys true= — show keys pressed in the mode indicator (debugging aid for bindings).
- =leavegithubalone true= — prevents Tridactyl from overriding GitHub's built-in keybindings.
- =allowautofocus false= — prevent pages from stealing keyboard focus on load.
- =jumpdelay 1500= — wait 1.5s before =]]= / =[[= next/prev page navigation fires;
  avoids accidental triggers.
- =scrollduration 100= — scroll animation duration in milliseconds (only applies when =smoothscroll= is enabled).
- =searchengine completions none= — disables the search completions source; queries
  that start with a known =searchurls= keyword use that engine directly.

* Clipboard and URL Tools

A full suite of yank operations lets you copy the page in any format needed
for notes, links, and git operations.

| Binding | Action                                          |
|---------+-------------------------------------------------|
| =yy=    | Yank canonical URL                              |
| =ys=    | Yank shortened URL                              |
| =yc=    | Yank canonical URL (full resolution)            |
| =ym=    | Yank as Markdown link =[title](url)=            |
| =yo=    | Yank as Org link =[[url][title]]= (clipboard)               |
| =yl=    | Capture link to today's journal Log (org-protocol journal-log)   |
| =yt=    | Capture TODO link in today's journal Tasks (org-protocol journal-task) |
| =ya=    | Save article as Denote reference note (org-protocol journal-article) |
| =yd=    | Save URL as Denote reference note (org-protocol denote-link)      |
| =yq=    | Generate QR code from URL (5s timeout)                           |
| =yg=    | Yank as =git clone= command (SSH format)                         |

* Aliases

Complex single-command operations.

- =translate= — inject Google Translate into any page in-place (no redirect)
- =get_current_url= / =current_url= — used by =N= / =O= bindings above
- =stop= — halt page load (like pressing Escape in the address bar)
- =mpvsafe= — open current link in mpv from a hint (shell-escapes the URL)
- =reibadailty= — `:jumble` alias (Tridactyl easter egg / internal alias)

=setnull translate= clears the =translate= setting to prevent it persisting
across sessions.
