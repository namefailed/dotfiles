* Overview

Basic Memory is a local, offline memory backend shared across all AI coding
assistants: Claude Code, Cursor, Windsurf, VS Code Copilot, and OpenCode.
Every memory is a plain Markdown file in =~/basic-memory/=. AI agents write and
read using MCP tools (=write_note=, =search_notes=, =build_context=, etc.).

* Files

- =basic-memory.org= — Literate configuration (MCP server config, bootstrap scripts)
- =start-basic-memory-server.ps1= — Login helper (tangled from [[file:../scripts/scripts.org][scripts.org]])
- =startup-orchestrator.vbs= — Startup orchestrator (Group 1 at logon, tangled from [[file:../scripts/scripts.org][scripts.org]])

* Org Safety

Org files are never modified by Basic Memory. Pandoc reads them as input and
writes new Markdown files into =~/basic-memory/bootstrap/=. Deleting
=~/basic-memory/= has no effect on the original org notes.

* Directory Layout

| Directory | Purpose |
|-----------+---------|
| =bootstrap/= | Agent bootstrap notes (auto-generated from Denote org files) |
| =config/= | Client-specific config notes |
| =projects/= | Project context notes |
| =reference/= | Reference notes (system state, tool docs, audit logs) |

* Backup

=~/basic-memory/= is a git repository with remote at =github.com/namefailed/basic-memory=.
=.gitattributes= enforces LF line endings to prevent CRLF issues.

* Reload

After editing =basic-memory.org=, tangle it. MCP config changes require
restarting the server: =basic-memory= or restart the VBS startup task.
