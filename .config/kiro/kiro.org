* Overview

Global configuration directory for Kiro, the AI-powered development tool. Moved here
from =~/.kiro= on 2026-05-19 as part of the home-root consolidation.

Note: Kiro also ships its own internal Bun runtime at
=%LOCALAPPDATA%\Kiro-Cli\bun= — that runtime is *not* managed here.

* Environment

=KIRO_HOME= is set as a persistent Windows user environment variable:

#+begin_example
KIRO_HOME = %USERPROFILE%\.config\kiro
#+end_example

Kiro resolves all global configuration paths against this directory. Project-level
config lives in =<project-root>/.kiro= and takes precedence over global settings.

* Directory Layout

| Path | Purpose |
|------+---------|
| =settings/cli.json= | Global CLI settings (currently empty defaults) |
| =sessions/= | Kiro CLI session state |
| =.cli_bash_history= | CLI command history |

* yadm Exclusion

Session state and CLI history are machine-local; only =settings/= is worth tracking.
