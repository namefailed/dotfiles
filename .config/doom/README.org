* Overview

User layer for Doom Emacs. Lives at =~/.config/doom= (=DOOMDIR=). Not part of the
batch =tangle all= scan for generic =~/.config/*.org= — tangle these files explicitly.

* Files

| File | Tangles to | Reload |
|------+------------+--------|
| =config.org= | =config.el= | =M-x doom/reload= |
| =init.org= | =init.el=, =packages.el= | =doom sync= + restart Emacs |

* Workflow

1. Edit =config.org= and/or =init.org=
2. =tangle config= / =tangle init= (or =M-x org-babel-tangle=)
3. =init.org= changes: =doom sync= in a terminal, then restart Emacs
4. =config.org= changes: =M-x doom/reload= usually sufficient
