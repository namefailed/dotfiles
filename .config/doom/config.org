This =config.org= file is the source of truth. Edit here, then tangle
with =tangle config= (or =M-x org-babel-tangle=) and reload with

* Bootstrapper =early-init.el=

Loaded before =init.el=, after Doom's core bootstrapper. The one essential
fix that must happen this early: Windows may launch the Emacs daemon with
=c:/Windows/TEMP/= as the working directory. Internal buffers (=*scratch*=,
=*Messages*=, etc.) inherit this as their buffer-local =default-directory=
at creation time, which causes =diff-hl--update= errors when it tries to run
=git= in those buffers. Changing the directory here ensures every buffer
created during startup gets =~/=, not TEMP.

#+begin_src emacs-lisp :tangle early-init.el :mkdirp yes
;;; $DOOMDIR/early-init.el -*- lexical-binding: t; -*-

;; =============================================================
;; DO NOT EDIT THIS FILE DIRECTLY.
;; Generated from ~/.config/doom/config.org
;; Edit that file, tangle with `tangle config`,
;; then restart Emacs.
;; =============================================================

;; Change the process CWD before Emacs creates internal buffers,
;; so they inherit ~/ instead of c:/Windows/TEMP/ (fixes diff-hl).
(cd "~/")
#+end_src

* Performance

Tuned for smooth editing of large org files. =redisplay-skip-fontification-on-input=
prevents Emacs from fontifying mid-keystroke. =read-process-output-max= raises the

re-center unless you scroll past the buffer boundary.

* Shell

Git Bash is the preferred shell: POSIX-compatible, present on every Windows
dev machine, and avoids PowerShell's startup overhead inside Emacs.
The =when= guard makes the config portable — machines without Git Bash fall
back to whatever Doom defaults to without erroring.

#+begin_src emacs-lisp
(let ((bash (executable-find "bash")))
  (when bash
    ;; Doom doctor checks that shell-file-name ends in /bash, /sh, etc.
    ;; On Windows executable-find returns bash.exe; strip .exe to satisfy
    ;; the check while keeping the full .exe path for terminal emulators.
    (setq shell-file-name (replace-regexp-in-string "\\.exe\\'" "" bash))
    (setq-default explicit-shell-file-name bash
                  vterm-shell bash)))
#+end_src

* Org Mode

Covers core variables, capture templates, agenda views, journal

** Core Settings

=org-directory= anchors everything. Agenda files are explicit — tasks,
projects, notes, and the journal — rather than recursive
to keep scans predictable. Past journal days are hidden from the agenda via
=org-agenda-skip-function-global= so only today and future datetree days
contribute journal TODOs (a clean slate for history). =org-hide-emphasis-markers= + =org-pretty-entities= give a clean
reading experience; [[*Org Appear][org-appear]] reveals the markers when the cursor
enters the construct. The TODO sequence mirrors GTD: =NEXT= for committed next
actions, =WAIT= for items blocked on external input. =org-tag-alist= defines
GTD =@context= tags (=@computer=, =@calls=, =@errands=, =@home=, =@homelab=,
=@read=, =@write=) available in all org files and filterable in the agenda.

#+begin_src emacs-lisp
(setq org-directory "~/Documents/org/"
      org-agenda-files (list (expand-file-name "tasks.org"    org-directory)
                             (expand-file-name "notes.org"    org-directory)
                             (expand-file-name "journal.org"  org-directory))

      org-default-notes-file (expand-file-name "journal.org" org-directory)
      org-log-done               'time
      org-startup-indented       t
      org-hide-emphasis-markers  t
      org-pretty-entities        t
      org-todo-keywords
      '((sequence "TODO(t)" "NEXT(n)" "WAIT(w)" "|" "DONE(d)" "CANCELLED(c)")))
(defconst my/org-journal-file
  (expand-file-name "journal.org" org-directory)
  "Canonical journal file used by the datetree workflow.")

;; GTD @context tags — available in all org files.

                      ("@homelab"  . ?l)

#+end_src

** Refile

Refile targets allow moving captured items to tasks or notes at up to
heading level 2. =org-refile-use-outline-path= prefixes the target with the
file name so identical headings in different files are unambiguous. Setting
=org-outline-path-complete-in-steps= to =nil= lets Vertico complete the full
path in one step rather than drilling down interactively.

** Agenda Views

The custom ="d"= (Daily Review) agenda is the main entry point each morning.
It stacks today's scheduled/deadline items, then next
actions and waiting items so nothing falls through the cracks. [[*Org Super Agenda][Org Super
Agenda]] groups these visually with labelled sections. Additional views: ="n"=
for next/todo, ="w"= for waiting (shows =WAITING_ON= property inline), ="c"=
prefix for @context filters (=cc=, =cp=, =ce=, =ch=, =cl=, =cr=, =cw=),
="S"= for the Someday / Maybe review.

=org-agenda-skip-function-global= skips any headline in =journal.org= whose
datetree day is strictly before today, so past journal days never surface in
the agenda while today and future days do.

#+begin_src emacs-lisp
(defun my/org-journal--outline-day-time-at-point ()
  "Return noon on the journal level-3 datetree day containing point, or nil."
  (save-excursion
    (ignore-errors
      (unless (org-at-heading-p)
        (org-back-to-heading t))
      (org-back-to-heading t)
      (while (> (org-outline-level) 3)
        (outline-up-heading 1 t))
      (when (= (org-outline-level) 3)
        (beginning-of-line)
        (when (looking-at "^\\*\\*\\* \\([0-9]\\{4\\}-[0-9]\\{2\\}-[0-9]\\{2\\}\\)")
          (pcase (mapcar #'string-to-number (split-string (match-string 1) "-"))
            (`(,y ,m ,d) (encode-time 12 0 0 d m y)))))))

(defun my/org-journal--today-midnight ()
  "Return encoded time at local midnight for today's calendar date."
  (pcase-let ((`(,sec ,min ,hour ,d ,m ,y . _) (decode-time (current-time))))
    (encode-time 0 0 0 d m y)))

(defun my/org-agenda-skip-journal-past-days ()
  "Skip journal subtrees whose datetree day is before today.
When not in `my/org-journal-file', return nil so other agenda files are unchanged."
  (when (and (derived-mode-p 'org-mode)
             buffer-file-name
             (file-equal-p (expand-file-name buffer-file-name)
                           (expand-file-name my/org-journal-file)))
    (let ((day (my/org-journal--outline-day-time-at-point)))
      (when (and day (time-less-p day (my/org-journal--today-midnight)))
        (save-excursion (org-end-of-subtree t t) (point))))))

(setq org-agenda-skip-function-global #'my/org-agenda-skip-journal-past-days)

(defun my/org-agenda-waiting-on ()
  "Return WAITING_ON property for agenda prefix, or empty string."
  (let ((w (org-entry-get nil "WAITING_ON")))
    (if (and w (not (string-blank-p w)))
        (format "[←%s] " w)
      "")))

(setq org-agenda-custom-commands
      `(("d" "Daily Review"
         ((agenda "" ((org-agenda-span 1)
                      (org-agenda-overriding-header "Today")))
          (todo "NEXT" ((org-agenda-overriding-header "Next Actions")))
          (todo "WAIT" ((org-agenda-overriding-header "Waiting / Follow Up")
                        (org-agenda-prefix-format
                         "  %(my/org-agenda-waiting-on)%-12:c%s")))))
        ("n" "Now (NEXT + TODO)"
         ((todo "NEXT" ((org-agenda-overriding-header "Next")))
          (todo "TODO" ((org-agenda-overriding-header "Unscheduled / inbox-style")))))
        ("w" "Waiting"
         ((todo "WAIT"
                ((org-agenda-overriding-header "Waiting / Follow Up")

                  "  %(my/org-agenda-waiting-on)%-12:c%s")))))
        ("c" . "Context views")
        ("cc" "@computer" ((tags-todo "@computer"
                            ((org-agenda-overriding-header "At computer")))))

** Journal

The journal lives in a single =journal.org= file using Org's datetree
structure (year → month → day). Each day's subtree gets a consistent
scaffold on first open:

- =s= (normal-mode) → append timestamped bullet to Log section
- =S= (normal-mode) → insert TODO heading in Tasks section
- Win+J → open journal with full day scaffold (Log/Tasks/EOD)

All three routes call =my/org-journal-ensure-day-structure=, which uses
a buffer-local guard (=my/org-journal-structure-ensured=) to scaffold at
most once per buffer visit. See [[*Journal Keybindings][Journal Keybindings]].

=my/org-journal-insert-timestamp= and =my/org-journal-insert-task= are bound
to =s= and =S= in normal mode inside =journal.org= only.

#+begin_src emacs-lisp
(defun my/org-journal--subtree-end ()
  "Return the end position of the subtree at point."
  (save-excursion
    (org-end-of-subtree t t)
    (point)))

(defun my/org-journal--goto-day-heading (time)
  "Move point to TIME's day heading in the current journal buffer."
  (goto-char (point-min))
  (re-search-forward
   (format "^\\*\\{3\\} %s$"
           (regexp-quote (format-time-string "%Y-%m-%d %A" time)))
   nil t))

(defun my/org-journal--goto-current-day-start ()
  "Move point to the current day's level-3 heading."
  (org-back-to-heading t)
  (while (> (org-outline-level) 3)
    (outline-up-heading 1 t))
  (beginning-of-line))

(defun my/org-journal--goto-heading-in-day (level heading)
  "Move point to HEADING at LEVEL within the current day's subtree."
  (my/org-journal--goto-current-day-start)
  (let ((day-end (my/org-journal--subtree-end)))
    (re-search-forward
     (format "^\\*\\{%d\\} %s$" level (regexp-quote heading))
     day-end t)))

(defun my/org-journal--gregorian-to-time (date)
  "Convert Gregorian DATE to an Emacs time value."
  (pcase-let ((`(,month ,day ,year) date))
    (encode-time 0 0 12 day month year)))

(defun my/org-journal--insert-day-template ()
  "Insert the current day's journal scaffold.
Point must be on the day heading line — moves to end of it so content
inserts after the heading, not before."
  (end-of-line)
  (insert
   (concat
      "\n\n**** Log\n"
      "- " (format-time-string "[%Y-%m-%d %a %H:%M]") " Day opened.\n\n"
      "**** Tasks\n\n"
      "**** EOD\n"
      "***** Done\n- \n\n"
       "***** Next\n- \n")))

(defun my/org-journal--ensure-top-section (heading &optional body)
  "Ensure the current day contains a level-4 HEADING with optional BODY."
  (unless (save-excursion (my/org-journal--goto-heading-in-day 4 heading))
    (my/org-journal--goto-current-day-start)
    (goto-char (my/org-journal--subtree-end))
    (insert (format "\n**** %s\n%s" heading (or body "")))))

(defun my/org-journal--ensure-child-section (parent child &optional body)
  "Ensure PARENT contains a level-5 CHILD heading with optional BODY."
  (when (my/org-journal--goto-heading-in-day 4 parent)
    (let ((parent-end (my/org-journal--subtree-end)))
      (unless (save-excursion
                (goto-char (line-beginning-position))
                (re-search-forward
                 (format "^\\*\\{5\\} %s$" (regexp-quote child))
                 parent-end t))
        (goto-char parent-end)
        (insert (format "\n***** %s\n%s" child (or body "")))))))

(defun my/org-journal--next-heading-point ()
  "Return the buffer position of the next heading after point.
If there is no later heading, return `point-max'."
  (save-excursion
    (forward-line 1)
    (if (re-search-forward "^\\*+ " nil t)
        (match-beginning 0)
      (point-max))))

(defvar-local my/org-journal-structure-ensured nil
  "Buffer-local guard: stores today's date `(month day year)` once the
day scaffold has been ensured for that date.  Nil means no scaffold has
been run yet.  Resets automatically when a new day is opened — compares
against `(calendar-current-date)` in `my/org-journal-ensure-day-structure`.

Checked via `unless` at the top of that function — NOT via
`cl-return-from', which would require an explicit `cl-block' wrapper
in Emacs Lisp.")

(defun my/org-journal-ensure-day-structure ()
  "Ensure today's subtree has the current journal scaffold.
Per-day guard (`my/org-journal-structure-ensured`) limits this to
once per day — safe to call from s, S, yl, yt, etc.

- Sections exist → ensure all present (Log/Tasks/EOD + child Done/Next)
- No sections → insert full template"
  (let ((today (calendar-current-date)))
    (unless (equal my/org-journal-structure-ensured today)
      (setq my/org-journal-structure-ensured today)
      (if (or (save-excursion (my/org-journal--goto-heading-in-day 4 "Log"))
              (save-excursion (my/org-journal--goto-heading-in-day 4 "Tasks"))
              (save-excursion (my/org-journal--goto-heading-in-day 4 "EOD")))
          ;; Has some content — ensure all sections exist
          (progn
            (my/org-journal--ensure-top-section "Log")
            (my/org-journal--ensure-top-section "Tasks")
            (my/org-journal--ensure-top-section "EOD")
            (my/org-journal--ensure-child-section "EOD" "Done")
            (my/org-journal--ensure-child-section "EOD" "Next"))
        ;; Completely fresh day — insert full template and carry forward
        (my/org-journal--insert-day-template)
        (my/org-journal--carry-forward-yesterday)))))

(defun my/org-journal--carry-forward-yesterday ()
  "Copy yesterday's open TODO items to today's Tasks section.
Each carried task gets (YYYY-MM-DD) appended for provenance.
The original stays in yesterday unchanged."
  (let* ((today (calendar-current-date))
         (yesterday (calendar-date-gregorian-from-absolute
                     (1- (calendar-absolute-from-gregorian today))))
         (yesterday-link (format-time-string "[%Y-%m-%d]"
                          (apply #'encode-time 0 0 0 0
                                 (list (nth 1 yesterday) (nth 0 yesterday) (nth 2 yesterday)))))
         tasks)
    (save-window-excursion
      (find-file my/org-journal-file)
      (org-datetree-find-date-create yesterday)
      (when (my/org-journal--goto-heading-in-day 4 "Tasks")
        (org-back-to-heading t)
        (let ((section-end (save-excursion (org-end-of-subtree t t) (point))))
          (forward-line 1)
          (while (< (point) section-end)
            (when (looking-at "^\\*\\*\\*\\*\\* TODO ")
              (let ((title (buffer-substring-no-properties
                            (match-end 0)
                            (line-end-position))))
                (unless (string-blank-p title)
                  (push title tasks))))
            (forward-line 1)))))
    (when tasks
      (find-file my/org-journal-file)
      (org-datetree-find-date-create today)
      (my/org-journal-ensure-day-structure)
      (my/org-journal--goto-tasks-section)
      (end-of-line)
      (dolist (task (nreverse tasks))
        (insert (concat "\n***** TODO " task " (" yesterday-link ")")))
      (save-buffer)
      (message "Carried forward %d task(s) from %s" (length tasks) yesterday-link))))

(defun my/org-journal--goto-section-end (level heading &optional empty-starter)
  "Go to the end of HEADING at LEVEL within the current day.
If the section is empty and EMPTY-STARTER is non-nil, insert it first.
Always measures the subtree from the section heading so nested headings
(e.g. ***** TODO under **** Tasks) stay inside the correct section."
  (when (my/org-journal--goto-heading-in-day level heading)
    (org-back-to-heading t)
    (let* ((heading-pos (point))
           (section-start (save-excursion (forward-line 1) (point)))
           (section-end (save-excursion
                          (goto-char heading-pos)
                          (org-end-of-subtree t t)
                          (point)))
           (contents (buffer-substring-no-properties section-start section-end)))
      (if (string-blank-p contents)
          (progn
            (goto-char section-start)
            (when (looking-at-p "^\\*+ ")
              (open-line 1))
            (when empty-starter
              (insert empty-starter)))
        (goto-char section-end)
        (skip-chars-backward "\n")
        (end-of-line)))
    (end-of-line)))

(defun my/org-journal-goto-log-section ()
  "Move point to the end of today's Log section."
  (my/org-journal--goto-section-end 4 "Log"))

(defun my/org-journal--goto-tasks-section ()
  "Move point to the end of today's Tasks section."
  (my/org-journal--goto-section-end 4 "Tasks"))

(defun my/org-journal-ensure-log-target ()
  "Ensure today's journal has a usable Log target.
Delegates to `my/org-journal-ensure-day-structure' which handles migration
from old-format days. Then positions point in the Log section."
  (require 'org-datetree)
  (find-file my/org-journal-file)
  (org-datetree-find-date-create (calendar-current-date))
  (my/org-journal-ensure-day-structure)
  (my/org-journal-goto-log-section))

(defun my/org-journal-ensure-tasks-target ()
  "Ensure today's journal has a usable Tasks target.
Delegates to `my/org-journal-ensure-day-structure' which handles migration
from old-format days. Then positions point in the Tasks section."
  (require 'org-datetree)
  (find-file my/org-journal-file)
  (org-datetree-find-date-create (calendar-current-date))
  (my/org-journal-ensure-day-structure)
  (my/org-journal--goto-tasks-section))

(defun my/org-journal-open-section-today (section)
  "Open today's journal and move point to SECTION."
  (interactive)
  (require 'org-datetree)
  (find-file my/org-journal-file)
  (org-datetree-find-date-create (calendar-current-date))
  (my/org-journal-ensure-day-structure)
  (pcase section
    ('plan
     (my/org-journal--goto-tasks-section))
    ('log
     (my/org-journal-goto-log-section))
    ('tasks
     (my/org-journal--goto-tasks-section))

     (my/org-journal-goto-log-section))))

(defun my/org-journal-capture-log-target ()
  "Open today's journal Log and return point for org-protocol capture.
Uses :insert-here so org-capture inserts at the section end, not at cursor
or the first list in the buffer (see `org-capture-place-item')."
  (set-buffer (find-file-noselect my/org-journal-file))
  (org-with-wide-buffer
    (my/org-journal-ensure-log-target)
    (end-of-line)
    (org-capture-put :insert-here t)
    (point)))

(defun my/org-journal-capture-task-target ()
  "Open today's journal Tasks and return point for org-protocol capture.
Leaves point on the **** Tasks heading so org-capture inserts a ***** TODO
at the bottom of that subtree (same as `my/org-journal-insert-task')."
  (set-buffer (find-file-noselect my/org-journal-file))
  (org-with-wide-buffer
    (my/org-journal-ensure-tasks-target)
    (unless (my/org-journal--goto-heading-in-day 4 "Tasks")
      (user-error "Browser task capture: could not find today's **** Tasks"))

(defun my/org-journal-process-eod ()
  "Scan today's Tasks section and populate EOD Done/Next.
Done (closed) items are collected under ***** Done.
Still-open items are collected under ***** Next.
Original tasks in Tasks are left intact."
  (interactive)
  (save-window-excursion
    (find-file my/org-journal-file)
    (org-datetree-find-date-create (calendar-current-date))
    (my/org-journal-ensure-day-structure)
    (let (done-items open-items)
      (when (my/org-journal--goto-heading-in-day 4 "Tasks")
        (org-back-to-heading t)
        (let ((section-end (save-excursion (org-end-of-subtree t t) (point))))
          (forward-line 1)
          (while (< (point) section-end)
            (cond
             ((looking-at "^\\*\\*\\*\\*\\* DONE ")
              (push (buffer-substring-no-properties (match-end 0) (line-end-position)) done-items))
             ((looking-at "^\\*\\*\\*\\*\\* TODO ")
              (push (buffer-substring-no-properties (match-end 0) (line-end-position)) open-items))
             ((looking-at "^\\*\\*\\*\\*\\* NEXT ")
              (push (concat "NEXT " (buffer-substring-no-properties (match-end 0) (line-end-position))) open-items))
             ((looking-at "^\\*\\*\\*\\*\\* WAIT ")
              (push (concat "WAIT " (buffer-substring-no-properties (match-end 0) (line-end-position))) open-items)))
            (forward-line 1))))
      (when (or done-items open-items)
        (my/org-journal--goto-heading-in-day 4 "EOD")
        (org-back-to-heading t)
        (when done-items
          (my/org-journal--goto-heading-in-day 5 "Done"))
        (when open-items
          (my/org-journal--goto-heading-in-day 5 "Next"))
        (setq my/eod-pending nil)
        (save-buffer)
        (message "EOD processed: %d done, %d open" (length done-items) (length open-items))))))

#+begin_src emacs-lisp
(defun my/denote--library-subdirectory (keywords)
  "Return absolute subdirectory under `denote-directory' for KEYWORDS.
Uses the same sorted + slugified keyword string Denote puts in filenames, then
maps a few special cases so cheatsheets stay under =personal/= and MOC under
=pkm/=."
  (unless keywords
    (user-error "Pick at least one keyword"))
  (let* ((sorted (denote-keywords-sort (copy-sequence keywords)))
         (slug-parts (denote-sluggify-keywords-and-apply-rules sorted))
         (combined (denote-keywords-combine slug-parts))
         (primary (car (split-string combined "_"))))
    (expand-file-name
     (concat
      (pcase primary
        ("cheatsheet" "personal")
        ("moc" "pkm")
        ((or "java" "tools" "personal" "pkm" "programming" "health"
             "homelab" "reference" "ai" "project" "work" "journal"
             "knowledge" "initiative" "voice" "web" "saved"
             "entertainment")
         primary)
        (_ "reference"))
      "/")
     (denote-directory))))

** System

=M-F4= closes daemon client frames with =delete-frame= instead of
=save-buffers-kill-terminal=. The safe path suppresses Doom workspace cleanup and
Emacs server client cleanup for the single frame being closed, preventing launcher-created
notes and Howm frames from deleting workspaces, prompting on modified Org
buffers, hanging, or leaving black windows. =M-S-F4= remains the intentional full
Emacs shutdown path.

#+begin_src emacs-lisp
(defun my/close-frame-or-kill-emacs ()
  "Close the current client frame in daemon mode; otherwise kill Emacs.
Bound to =M-F4= so the standard Windows close gesture deletes a client frame
without prompting for unsaved buffers or tearing the daemon down."
  (interactive)
  (if (and (daemonp) (frame-parameter nil 'client))
      (let ((delete-frame-functions
             (remq '+workspaces-delete-associated-workspace-h
                   delete-frame-functions))
            (server-done-hook
             (remq '+workspaces-delete-associated-workspace-h
                   server-done-hook)))
        (delete-frame))
    (save-buffers-kill-terminal)))

(map! "M-<f4>"   #'my/close-frame-or-kill-emacs
      "M-S-<f4>" #'save-buffers-kill-terminal)

(defun my/disable-workspaces-delete-associated-workspace (&rest _)
  "Override advice that prevents Doom from deleting workspaces on frame close."
  nil)

(defun my/launcher-frame-p (&optional frame)
  "Return non-nil if FRAME was marked as the launcher frame."
  (frame-parameter frame 'my/launcher-frame))

(defun my/safe-delete-frame (frame)
  "Delete FRAME without triggering Doom workspace or server cleanup.

Suppresses `delete-frame-functions' and `server-done-hook' handlers that
would delete the associated workspace or kill the Emacs client, so daemon
client frames can be closed individually without side effects."
  (let ((delete-frame-functions
         (remq 'server-handle-delete-frame
               (remq '+workspaces-delete-associated-workspace-h
                     delete-frame-functions)))
        (server-done-hook
         (remq '+workspaces-delete-associated-workspace-h
               server-done-hook)))
    (delete-frame frame t)))

(defun my/handle-delete-frame (event)
  "Handle a `delete-frame' EVENT from Emacs's special-event-map.

Daemon client frames are deleted via `my/safe-delete-frame'. All other
frames are handled by Emacs's default `handle-delete-frame'."
  (interactive "e")
  (let ((frame (posn-window (event-start event))))
    (if (and (daemonp)
             (framep frame)
             (frame-parameter frame 'client))
        (my/safe-delete-frame frame)
      (handle-delete-frame event))))

(advice-remove '+workspaces-delete-associated-workspace-h
               #'my/disable-workspaces-delete-associated-workspace)
(advice-add '+workspaces-delete-associated-workspace-h
            :override #'my/disable-workspaces-delete-associated-workspace)
(remove-hook 'delete-frame-functions #'+workspaces-delete-associated-workspace-h)
(remove-hook 'server-done-hook #'+workspaces-delete-associated-workspace-h)
(define-key special-event-map [delete-frame] #'my/handle-delete-frame)
#+end_src

* Startup

New client frames inherit the working directory of the process that launched
them. When Kanata's =LWin+Enter= calls =emacsclientw= from =wscript.exe=, that
directory is =C:\Windows\System32=, which breaks project discovery and
=find-file= defaults. Both hooks normalize =default-directory= to =~= on init
and on every new frame.

#+begin_src emacs-lisp
(defun my/emacs-home-default-directory ()
  "Set default-directory to HOME for the initial frame."
  (setq default-directory (expand-file-name "~/")))

(defun my/emacsclient-frame-default-directory (_frame)
  "Normalize default-directory for every new client frame.
Prevents inheriting wscript.exe's C:/Windows/System32 working directory
when frames are launched via Kanata's LWin+Enter binding.
If the current buffer has a file inside ~/Documents/org/ (the notes git
repo), leave default-directory at the file's directory so vc-git-root
and diff-hl resolve the notes repo, not the YADM dotfiles repo."
  (if (and buffer-file-name
           (string-prefix-p (expand-file-name "~/Documents/org/")
                            (expand-file-name buffer-file-name)))
      (setq default-directory (file-name-directory buffer-file-name))
    (setq default-directory (expand-file-name "~/"))))

(add-hook 'after-init-hook          #'my/emacs-home-default-directory)
(add-hook 'after-make-frame-functions #'my/emacsclient-frame-default-directory)

** Org Protocol

External capture via =org-protocol://= URLs (Firefox Tridactyl =yl=/=yt=, bookmarklets, or any app that can open a URL).

| Tridactyl | Protocol               | Same as in =journal.org= | Lands at |
|-----------+------------------------+--------------------------+----------|
| =yl=      | =journal-log=          | =s=                      | Bottom of today's **** Log |
| =yt=      | =journal-task=         | =S=                      | Bottom of today's **** Tasks |
| =ya=      | =journal-article=      | —                        | New Denote reference note + journal Log link |
| =yo=      | —                      | —                        | Clipboard =[[url][title]]= only |
| =yd=      | =denote-link=          | —                        | New Denote reference note, no journal entry |

Custom protocol handlers (=my/org-protocol-journal-log=, =my/org-protocol-journal-task=)
bypass org-capture entirely — they open journal.org, navigate to the right section,
insert the link directly (same navigation code as =s=/=S=), and save. No capture window.
The legacy =l=/=jt= capture templates were removed to prevent double-firing.

Setup (once per machine; Emacs daemon required for =yl=/=yt=):

1. Run =~/.config/scripts/archive/utility/register-org-protocol.ps1= (archived; once per machine)
   (registers =emacsclientw -a emacs "%1"= without =-c= so captures reuse the open frame).
2. =(setq org-protocol-always-new-frame nil)= (below).
3. Reload Doom after edits: =M-x doom/reload=.

Bookmarklet (Log only):

#+begin_example
javascript:location.href='org-protocol://journal-log?url='+encodeURIComponent(location.href)+'&title='+encodeURIComponent(document.title)
#+end_example

Tasks bookmarklet: same URL with =journal-task= (see [[denote:20260517T120000][Browser Journal Capture]]).

(defun my/org-protocol-journal-log (data)
  "Insert a browser link into today's Log section (same as `s' but with link).
DATA is the org-protocol plist with :url, :title, and optional :note."
  (let* ((url   (or (plist-get data :url) ""))
         (title (or (plist-get data :title) url))
         (note  (or (plist-get data :note) ""))
         (ts    (format-time-string "- [%Y-%m-%d %a %H:%M] ")))

    (my/org-journal-ensure-day-structure)
    (my/org-journal-goto-log-section)
    (end-of-line)
    (newline)
    (insert ts "[[" url "][" title "]]")
    (unless (string-empty-p note)
      (insert " " note))
    (insert " ")
    (save-buffer)))

(defun my/org-protocol--slugify (s)
  "Convert S to a Denote-compatible file slug."
  (let ((slug (downcase (string-trim s))))
    (setq slug (replace-regexp-in-string "[^a-z0-9 ]" "" slug))
    (setq slug (replace-regexp-in-string " +" "-" slug))
    (setq slug (replace-regexp-in-string "-+" "-" slug))
    (setq slug (replace-regexp-in-string "^-\\|-$" "" slug))
    (if (string-empty-p slug) "untitled" slug)))

(defun my/org-protocol-journal-article (data)
  "Save extracted article body as a Denote reference note.
Adds a link in today's journal Log.
DATA is the org-protocol plist with :url, :title, and :body."
  (let* ((url         (or (plist-get data :url) ""))
         (title       (or (plist-get data :title) url))
         (body        (or (plist-get data :body) ""))
         (now         (current-time))
         (identifier  (format-time-string "%Y%m%dT%H%M%S" now))
         (denote-date (format-time-string "[%Y-%m-%d %a]" now))
         (journal-ts  (format-time-string "[%Y-%m-%d %a %H:%M]" now))
         (slug        (my/org-protocol--slugify title))
         (target-dir  (expand-file-name "saved"
                        (expand-file-name "notes" org-directory)))
         (fname       (format "%s/%s--%s__saved_web.org"
                               target-dir identifier slug))
         (denote-link (format "[[denote:%s][%s]]" identifier title)))
    ;; Create target directory if needed
    (make-directory target-dir t)
    ;; Write Denote note
    (with-temp-file fname
      (set-buffer-file-coding-system 'utf-8)
      (insert (format "#+title:      %s\n" title))
      (insert (format "#+date:       %s\n" denote-date))
      (insert "#+filetags:   :saved:web:\n")
      (insert (format "#+identifier: %s\n" identifier))
      (insert "\n* Source\n\n")
      (insert (format "[[%s][%s]]\n\n" url title))
      (when (org-string-nw-p body)
        (insert "* Summary\n\n")
        (insert (replace-regexp-in-string
                 "[^[:print:]\n\t]" " "
                 (string-trim body))
                "\n")))
    ;; Log in today's journal
    (require 'org-datetree)
    (find-file my/org-journal-file)
    (org-datetree-find-date-create (calendar-current-date))
    (my/org-journal-ensure-day-structure)
    (my/org-journal-goto-log-section)
    (end-of-line)
    (newline)
    (insert (format "- %s Saved article: %s\n" journal-ts denote-link))
    (save-buffer)))
